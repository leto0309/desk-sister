# 陪主人玩 Balatro

**中文** · [English](balatro.en.md)

右键她或托盘图标，点「陪我玩 Balatro」：她通过 BalatroBot mod 读取牌局、自己出牌，边打边在气泡里解说
（比如「留这对 K，凑葫芦」）；两句之间至少隔 15 秒，免得看不过来，回应你的建议和开打新盲注时不受这个限制。
打牌时用「和她说话」说的话是给她的建议，她在下一步参考后决定采不采纳。
再点一次同一个菜单项（已勾选）就不玩了。

她不看屏幕、不动鼠标键盘：游戏只经 mod 在本机 `127.0.0.1` 开放的接口读写，你照常用电脑。
游戏要一直开着，但不必放在前台，最小化也能继续打（2026-11-02 实测）；关掉游戏她就会停下。

她水平一般：实测通常输在底注 1–4，最远打到底注 4 的 Boss，打满 8 个底注不现实。这是陪玩和解说，不是通关工具。

## 需要先装的东西（主人自己装，桌宠不会去改游戏）

以下版本在 2026-10-31 实测可用（Balatro 1.0.1o，Steam 版）。**最新的 Steamodded 26.x 与 BalatroBot 1.5.2 不兼容**
（开局时报 `viewed_back` 为空），请用下面这个版本。

| 组件 | 版本 | 放到哪里 |
|---|---|---|
| [Lovely Injector](https://github.com/ethangreen-dev/lovely-injector/releases) | v0.10.0（`lovely-x86_64-pc-windows-msvc.zip`） | 解压出的 `winmm.dll` 放进游戏目录（Steam 里右键 Balatro → 管理 → 浏览本地文件） |
| [Steamodded](https://github.com/Steamodded/smods/releases) | 1.0.0-beta-1620a | 源码包解压后整个文件夹改名为 `smods`，放进 `%APPDATA%\Balatro\Mods\` |
| [BalatroBot](https://github.com/coder/balatrobot/releases) | v1.5.2 | 只要 `balatrobot.json`、`balatrobot.lua` 和 `src\lua\`，放进 `%APPDATA%\Balatro\Mods\balatrobot\` |

装好后照常从 Steam 启动 Balatro；mod 会在 `127.0.0.1:12346` 开放接口（不需要 BalatroBot 自带的 Python 启动器）。

装 mod 之前建议先备份 `%APPDATA%\Balatro`（存档和设置）。

## mod 会改变的游戏设置

BalatroBot 加载后会把游戏静音、游戏速度调到 4 倍、关闭新手提示，这是它自己的行为，与桌宠无关；
只要 mod 还装着，自己玩时也是这样。不想要时按下面的方法卸载；卸载后如果声音或速度没恢复，在游戏选项里调回来。

## 卸载

1. 关闭 Balatro。
2. 删除游戏目录里的 `winmm.dll`。
3. 删除 `%APPDATA%\Balatro\Mods` 里的 `smods`、`balatrobot` 和 `lovely` 文件夹；别的 mod 留着，文件夹空了可以一起删。`%APPDATA%\Balatro\config\Steamodded.jkr` 如果有，也是 mod 留下的，可以一起删。

存档不用动，卸载不影响进度。**不要**为了卸载用旧备份覆盖 `%APPDATA%\Balatro`：那会丢掉备份之后的所有进度。
只有确实想回到安装前的进度时才这样做，并先另存一份当前的文件夹；Steam 云存档若提示冲突，选本地文件。

## 她怎么打

- 主菜单时用 `balatro_deck`（默认蓝色牌组）、白注开一局；已有进行中的一局就接着打；游戏停在结束画面时回主菜单再开一局。
- 出牌时她拿到的提示里有本地算好的最好牌型和估分（只算写明牌型的小丑）、还差多少分、平均每手要多少分；估分不够时会被提醒先弃牌凑大牌型。
- 选盲注（一律选择，不跳过）、兑现和用星球牌由本地规则完成，不调用模型。星球牌一拿到就用；买了「天文台」优惠券时留在手里才有加成，就不自动用。
- 塔罗牌：提示里标明每张牌要不要选牌、选几张。不用选牌的（女祭司、皇帝、隐者、节制、审判、命运之轮）能起作用时程序直接用；强化类在出牌时由程序用：魔术师、皇后、教皇、正义用在要计分的牌上，战车、恶魔用在留在手里的牌上（钢铁和黄金要留在手里才生效）。其余的（愚者、恋人、力量、倒吊人、死神、高塔、改花色的四张）由她决定。你刚提了建议时不自动用；游戏拒绝过一次后，这局不再自动用牌。
- 出牌/弃牌、逛商店、开卡包，每一步调用一次你在设置里选的模型（只发文字的牌局状态，没有截图）。
  模型的操作经过白名单和编号检查才执行；不合规或调用失败时按本地规则出牌（本地判断出的最好牌型）、
  离开商店、跳过卡包。
- 盖着的牌她看不到：mod 虽然会报告真实点数，桌宠不会告诉模型，也不计入估分。
- 她说的牌名、牌型和盲注名与游戏里的中文一致（比如 Hanging Chad 是「未断选票」）：mod 只报告英文名，桌宠开始打牌时从 Steam 里装的 `Balatro.exe` 读游戏自带的中文语言文件（只读，不运行、不修改）。读不到时让模型自己说中文，可能和游戏里的译名不同。
- 逛商店时她拿到利息规则、现在可得的利息和每件商品买后的利息，买东西前会权衡。
- 钱由本地规则把关：买完至少留 $5×当前底注（封顶到满额利息，通常 $25）；小丑不足 3 张时买小丑不受限；存够满额利息才刷新（免费刷新不限）。
  她想买线下的东西时，这一步直接离开商店。你刚提了建议时这一步不限制，让她买她就能买。绿色牌组没有利息，不受限。
- 小丑不足 3 张时，商店里有买得起、放得下的小丑，提示会让她优先买；她什么都不买就要走时，程序替她买下最便宜的那张。你刚提了建议时不强制。
- 钱超过满额利息（通常 $25）时，多出的钱不生利息：她什么都不买就要走时，程序替她花，花完不低于满额利息线。依次是放得下的小丑（先选写明牌型加成的）、星球牌、优惠券；都没有而小丑槽位还有空时刷新商店。卡包不代买。你刚提了建议时不强制。
- 有了至少 2 张小丑后，她会定一个这局的主打牌型并一直记着，买牌时优先配合它，确实该换才换；手里已有更大的牌型就先出，不为它拆牌。程序把依据算好告诉她：哪些牌型出得最多、哪些升过级、已有小丑偏向哪种牌型。下一局重新定。
- 出牌基本由程序把关：每一手如果她选的牌估分不到最好牌型的 60%，又不够过这个盲注，就换成最好牌型。估分算上写明牌型的小丑（比如三条 +100 筹码），其他小丑算不了，所以留了余量。你刚提了建议时这一步不替换。
- 对出牌有规则的 Boss 由程序把关：灵媒（The Psychic，必须出 5 张）、眼睛（The Eye，不能出重复牌型）、嘴（The Mouth，只能出同一种牌型）。最好牌型只从能得分的牌里挑，她出的牌会得 0 分时换成最好牌型（你刚提了建议时不换）。
- 弃牌也有把关（你刚提了建议时不管）：要弃的牌拆了顺子及以上的牌型，或拆了估分已经够用的牌型时，改成直接出这手；还有弃牌次数却要出一张不够过关的高牌时，改成弃牌，留下最好牌型和最接近同花或顺子的牌。她主要负责其余的弃牌、买牌和解说。
- 模型调用失败时她不急着出牌，先等 15、30、60 秒重试；还不行才按本地规则走。
- 游戏拒绝的操作（比如钱不够）她会说出原因并重新决定；连续 3 次被拒改用本地规则，连续 6 次或连不上游戏就不玩了。
- 打满 `balatro_target_ante`（默认 8）个底注或游戏结束时说一句总结并停下，不进入无尽模式，也不会自动开下一局。
- 暂停（Ctrl+Alt+P）会立即停在当前一步，恢复后接着打。

## 设置项（暂时只能在 `%APPDATA%\ClaudePet\config.json` 里改）

| 键 | 默认 | 说明 |
|---|---|---|
| `balatro_deck` | `"BLUE"` | 新开一局用的牌组：RED、BLUE、YELLOW、GREEN、BLACK、MAGIC、NEBULA、GHOST、ABANDONED、CHECKERED、ZODIAC、PAINTED、ANAGLYPH、PLASMA、ERRATIC |
| `balatro_target_ante` | `8` | 打到第几个底注为止（1–8） |
| `balatro_port` | `12346` | mod 的端口，与 BalatroBot 的 `BALATROBOT_PORT` 一致（1024–65535） |
| `balatro_thinking_tokens` | `0` | 走 Claude 订阅时，每一步允许模型隐藏思考多少 token（0–8000）。设置「常规」页的「打牌模式」就是改它，见下面的额度 |

## 额度

每一步出牌或商店决定是一次模型调用，一局通常有一两百次。走 Claude 订阅时会消耗订阅额度；选 API Key 方式时按量计费。

模型默认会先隐藏思考几千 token，一条两行的回答要等将近一分钟，所以打牌时默认关掉。在设置「常规」页的「打牌模式」可以选（走 Claude 订阅时才生效，打牌中途换了下一步就生效）。2026-11-02 用 Haiku 对同一手牌实测：

| 打牌模式 | `balatro_thinking_tokens` | 每步耗时 | 每步输出 token |
|---|---|---|---|
| 陪玩模式（默认） | `0` | 4–6 秒 | 约 50–260 |
| 认真模式 | `2000` | 14–24 秒 | 约 1300–2300 |
| 不限（桌宠的其他对话） | — | 29–61 秒 | 约 3300–7400 |
