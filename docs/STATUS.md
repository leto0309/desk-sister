## 发布流程要点

1. 在开发仓库更新版本号并合并。
2. 用 `devtools/Sync-PublicRepo.ps1` 预览，确认后加 `-Push` 同步到公开仓库。
3. 在公开仓库手动触发 `release.yml`，输入版本号。
4. 发布后核对附件哈希（`SHA256SUMS.txt` 与 GitHub 提供的哈希），并运行 `desk-sister.exe --self-test`，再补写 Release 说明。
