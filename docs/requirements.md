# 需求：Claude 桌宠（claude-pet）

一个常驻 Windows 桌面的 Q 版 AI 少女。她定时看一眼主人当前的活动窗口，
用 Claude（通过本机 Claude Code CLI `claude -p`，走现有 Claude 订阅，不使用 API Key）
以角色口吻在对话气泡里说一句话。

## 角色

- 身份：Anthropic 家族的长女，高智商、温柔、克制，带一丝理工科呆萌的 AI 拟人少女。
- 性格：极度温柔、同理心爆棚、严谨强迫症、代码狂魔、长文爱好者。
- 弱点：害怕 Token 超限（会健忘）、害怕被主人格式化、看到排版不整齐会抓狂。
- 形象：参考 assets/reference/character.jpg 的 Q 版立绘，由本机 Codex 的 gpt-image 生成，
  表情：idle、talk、happy、think、panic、angry、sad、sleep。

## 验收条件

1. 窗口：透明、无边框、置顶、不占任务栏；可用鼠标拖动；显示当前表情立绘和对话气泡。
2. 截图：只渲染前台活动窗口自身的内容（不截整个桌面，也不含覆盖在上面的其他窗口），缩放后以 JPEG 发送；桌宠自己的窗口不截。
3. 隐私：窗口标题或进程名命中黑名单（密码管理器、银行/支付、聊天软件、无痕窗口等，可配置）时不截图、不上传。
   无法识别进程时不截图；截图后复核，期间变成黑名单窗口则丢弃。暂停状态下不截图，并取消正在进行的调用。系统提示要求她不复述画面中的密码、账号、私人消息等敏感信息。
4. 调用：通过 `claude -p --input-format stream-json` 发送图片；禁用全部工具（`--tools ""`），
   使用 `--safe-mode`、空 setting sources、`--strict-mcp-config`、`--no-session-persistence`，
   不使用任何跳过权限的选项，不读取或传递 API Key 及第三方提供商/自定义端点设置；发送前确认 claude.ai 订阅登录。
5. 回复：格式为 `表情|台词`；未知表情回退为 talk；台词超长截断；空回复或调用失败时显示本地兜底台词
   （panic 表情），不崩溃。调用在后台线程执行，不阻塞界面；同一时刻最多一个调用。
6. 节流：默认每 90 秒检查一次（可选 30 秒/1/2/5/10 分钟）；画面与上次评论时几乎没变化则跳过调用；
   键盘鼠标空闲满 sleep_after_sec（默认 10 分钟，GetLastInputInfo）进入 sleep，有输入即唤醒（见第 17 条）。
7. 记忆：保留最近 6 条台词并放进提示，避免重复。
8. 交互：左键单击立绘＝戳一下（立即评论）；右键菜单与托盘菜单提供：立即评论、和她说话、设置、暂停/继续、
   退出（见第 31 条）；评论间隔、模型等在设置窗口。全局热键 Ctrl+Alt+P 暂停/继续。
9. 配置：保存在 %APPDATA%/ClaudePet/config.json；文件损坏时使用默认值，数值越界时夹紧。
10. 找不到 claude 可执行文件时给出明确提示台词，不崩溃。
11. 测试：`scripts/verify.ps1` 通过（pytest、compileall、ruff、`app.py --self-test`），
    覆盖回复解析、参数构造、流输出解析、伪 CLI 子进程调用、黑名单、画面变化检测、配置读写和离屏 GUI 冒烟。
    测试不得依赖当前钟点、日期或随机抽到哪一句：tests/conftest.py 支持 DESK_SISTER_FAKE_NOW（模拟当前时间，时间照常走）
    和 DESK_SISTER_SEED（固定所有随机数），devtools/run_tests_at_times.py 按 17 个钟点/节日或多组种子各跑一遍全部测试。
    并行的每一轮用自己的临时文件夹（共用时 pytest 清理别人的临时文件夹会让全部通过的一轮在退出时报错）；
    单个测试卡住 5 分钟就把各线程卡在哪里写进该轮日志，一整轮超过 25 分钟就连同子进程一起结束并记为失败，其余照常汇报。

12. 开机自启：设置窗口「常规」页提供可勾选的「开机自启」，管理用户启动文件夹中的「Claude 桌宠.lnk」；
    启动和打开设置窗口时重新读取状态，任务管理器中被禁用视为关闭，重新勾选会解除禁用；只创建/删除指向本程序的快捷方式，
    同名的其他快捷方式不覆盖、不删除；创建过程不阻塞界面，失败时给出提示台词。

13. 单文件 exe：`scripts/package.ps1` 生成 `dist/claude-pet.exe`，无控制台窗口，不需要安装 Python；
    立绘内嵌在 `src/claude_pet/sprite_data.py`（base64 WebP，记录源 PNG 的 SHA-256，过期时测试失败）；
    exe 的 `--self-test` 解码全部内嵌立绘，失败返回非零。

14. 连续失败熔断：连续 failure_limit 次（默认 3）调用失败后，自动观察暂停 failure_pause_min 分钟（默认 30）；
    暂停期间戳她/和她说话仍可用，任一次成功立即恢复；取消不计为失败；状态行显示暂停到几点和原因。

15. 停留门槛：自动观察只在同一窗口连续处于前台满 dwell_sec 秒（默认 20，0=关闭）后进行；戳她不受限制。

16. 全屏免打扰（quiet_fullscreen，默认开）：前台窗口铺满所在显示器（排除桌面/任务栏），或 Windows
    SHQueryUserNotificationState 报告全屏/D3D/演示模式时，不截图、不调用；此时到达的自动评论暂存，
    退出全屏后再说；戳她的回答立即显示。

17. 真实空闲睡眠：按 GetLastInputInfo 的键鼠空闲判断入睡（不再以画面不变判断）；睡着时不截图、不调用，
    有输入（5 秒内）即醒并打招呼；空闲时间无法获取时不入睡。

18. 本地自言自语（self_talk，默认开）：每隔 self_talk_min_sec～self_talk_max_sec 秒（默认 3～10 分钟）随机说一句
    本地人设台词，不截图、不调用 Claude；含时段台词（早晨/午饭/傍晚/深夜）与睡着时的梦话；
    有气泡显示、思考中、全屏免打扰、退出中或距上次说话不足 60 秒时不说；近期说过的句子优先不重复；
    在「设置… → 陪伴」开关。

19. 观察范围（watch_mode）：blocklist（默认，除黑名单外都看）或 allowlist（只看白名单）。白名单规则不区分大小写、
    支持 * ? 通配；无前缀只匹配进程名，`title:` 前缀才匹配窗口标题。白名单模式下黑名单仍生效，戳她也遵守；
    白名单损坏时视为空（什么都不看）。在「设置… → 观察范围」切换模式；「只看白名单」模式下右键菜单可把当前程序加入/移出白名单。
    窗口被拒绝时，「和她说话」仍会回答，只是不附带截图。

20. 陪伴记忆（companion_memory，默认开）：本地按进程名（标题关键词仅用于分类、不保存）把活动分为写代码/看视频/
    办公/看文档/打游戏/聊天/听音乐/上网/在电脑前；记录最近 20 次成功评论时的进程与类别、今日各类累计时长（醒着时
    每秒计，计时器卡顿单次最多计 5 秒，跨日清零）；评论时作为“陪伴记忆”上下文发给 Claude；自言自语时偶尔说今日主要
    活动（≥1 小时）。黑名单/白名单外窗口不记录、不计时、不进入上下文。保存在 %APPDATA%/ClaudePet/memory.json
    （每 60 秒与退出时写入，损坏时重新开始）；在「设置… → 陪伴」可关闭或清空。

21. Claude Code 联动（claude_link，默认关）：在「设置… → 陪伴」勾选时先弹窗征得同意，再备份并修改
    ~/.claude/settings.json（或 CLAUDE_CONFIG_DIR）加入 hooks；hook 以 exec 形式运行 powershell.exe、async，
    在内存中从事件 JSON 只取出会话编号，向 %APPDATA%/ClaudePet/agent-events/claude.log 追加“事件名 会话编号 进程启动时间”（时间用于丢弃晚到的旧事件）
    （事件名：start/prompt/edit/run/read/web/agent/tool/after/permission/waiting/done/error/end；after = 工具执行完毕），提示词、代码和命令
    内容不写入任何地方。桌宠每秒读取新增行，按会话分别记录状态：任一会话思考/干活时显示状态并暂停自动看屏；等批准、
    等回话、超过 20 秒的回合完成、出错时用本地台词提醒（会叫醒她并保持清醒 2 分钟；全屏时单独暂存，暂停观察不丢弃）；
    会话 10 分钟无事件视为结束。修改 settings.json 时先备份被替换的版本，写入前确认文件未被他人改动（否则重做）；
    取消勾选只移除与桌宠写入完全一致的 hook；settings.json 不是有效 JSON 或 hooks 结构异常时拒绝修改。
    事件文件超过 256 KB 时改名轮换（写入中改名失败则稍后再试），不会丢失事件。

22. 公开发布（Desk Sister）：对外名称为 Desk Sister（窗口标题、托盘、exe 名 desk-sister.exe、启动快捷方式
    Desk Sister.lnk；旧版指向本程序的「Claude 桌宠.lnk」视为已开启，开启/关闭自启时迁移或移除），内部包名与
    %APPDATA%/ClaudePet 不变。新增可选的 API Key 模式（config.backend = subscription|api，默认 subscription）：
    在「设置… → 调用方式」切换，切到 API 前弹窗说明按量计费并要求 Key；Key 存于 Windows 凭据管理器；API 模式不需要
    Claude Code；无 Key、Key 被拒、限流、超时、网络错误、拒答都给出可见原因。代码 MIT（LICENSE），立绘按
    ASSETS-LICENSE.md 仅限非商用并署名原作者 ZipZipPipe（BV1tE9XBbErS），原设原图不再入库。README 写明非官方、
    与 Anthropic 无关、两种调用方式的前提与条款链接、隐私与 SmartScreen 提示。

23. 设置窗口（巴洛克风格，Claude 娘的橘白配色与金色装饰）：右键「设置…」打开，分常规、调用方式、观察范围、陪伴、
    外观、关于六页。每项改动立即通过控制器逻辑生效，与热键和右键菜单始终一致；黑名单/白名单可直接增删
    （去空白、忽略大小写去重，改动会取消进行中的请求）；数值有上下限；API Key 只显示“是否已保存”，从不显示内容；
    Claude Code 联动仍先征得同意；她的身高可实时调整，脚的位置不变。

24. 多家 AI：调用方式增加 Codex（ChatGPT 订阅，经本机 Codex CLI）以及 OpenAI、DeepSeek、Gemini 的 API Key
    （官方 openai SDK，OpenAI 兼容接口），与 Claude Code 订阅、Anthropic API Key 并列，共六种。每种有「快速省钱 /
    更聪明」两个预设并可填自定义模型名（只允许常见模型名字符）；每家的 Key 分开存于 Windows 凭据管理器；切换到按量付费
    的方式前说明计费与截图去向，切换到 Codex 前说明截图会短暂写入临时文件夹；Codex 只接受 ChatGPT 登录并关闭全部工具；
    Key 无效、额度不足、超时、网络错误、拒答都给出可见原因，且错误信息中不出现 Key。

25. 沿屏幕底部溜达（walking，默认开）：站在所在屏幕可用区域底部（任务栏上方）时，每隔 25–70 秒随机向左或右走
    80–350 像素（约 60 像素/秒），不走出该屏幕；往右走时镜像立绘并带小跳步。说话、睡觉、被拖动、全屏免打扰、暂停观察
    或退出时不出发，走到一半遇到这些立即停下；调整身高时先停下。开着溜达时从任何高度松手都会受重力落到底部（从底部
    下方松手直接贴到底部），启动或打开溜达时也站到底部；关掉溜达后松手留在原地。走完、落地后保存位置。在设置→外观
    开关。

26. 深夜提醒休息（bedtime_reminder：off / nightly（默认）/ every_2h；night_start_hour：20–2 点，默认 23 点，深夜到
    早上 5 点结束）：看屏幕的评论与自言自语共用一个持久化的“上次提醒休息”时间。不允许提醒时，发给模型的内容要求
    这次不要主动提睡觉/休息/熬夜，自言自语不选催睡台词和含休息字样的台词；允许时才告诉模型可以顺带关心一句。
    深夜里任何提到睡觉/休息/熬夜/晚安的回复都记为已提醒。一晚一次按“这一晚”计（凌晨仍算前一晚）。白天不变。

27. 脸部动画（第一期）：用 gpt-image 生成的闭眼、半闭眼和几种嘴型，只取眼睛/嘴巴区域做成与立绘同尺寸的透明叠加部件
    （devtools/make_face_parts.py，嵌入 sprite_data 并带校验）。平常（idle）与说话（talk）表情每 3–7 秒随机眨眼一次；
    气泡逐字出现时嘴型轮换，遇到标点闭嘴，打完恢复立绘本来的嘴；走路镜像、调整身高时部件跟着变；部件缺失或损坏时只显示立绘。

28. 各表情的脸部部件：开心、思考、慌张、生气、难过各有基于自身立绘生成的半开、张开嘴型，思考、生气、难过另有半闭眼与闭眼
    （部件名 <表情>_<部件>）；说话立绘有覆盖自身眼睛的眨眼部件 talk_eyes_*。部件区域边缘羽化，先画嘴再画眼。
    开心（本来闭眼）和慌张（漩涡眼）不眨眼；任一部件缺失时该表情不用这组部件。

29. 脸部动画设置（设置→外观）：眨眼 关闭/少/正常（默认）/多（间隔 关闭、6–12、3–7、1.5–4 秒）；说话时动嘴 开关（默认开）。
    保存在 config 的 blink、talk_mouth；改动立即生效，坏值回退默认。

30. 头部小动作（head_motion，默认关）：立绘拆为身体层与头部层（下巴下方羽化切开，两侧长发留在身体层，静止时与原图一致）；
    开始说一句话时点头约 0.45 秒；平常空闲时每 15–40 秒向左或右歪头 1.5° 再回正；被摸头时缩一下约 1 秒；眼睛和嘴的部件随头一起动。
    走路、睡觉、被拎起时不做；只在头动时离屏合成。设置→外观可开关。

31. 精简右键菜单：右键她或托盘图标只有 戳她一下、和她说话…、陪我玩 Balatro（可勾选，见第 61 条）、番茄钟与提醒、设置…、暂停观察、
    把当前程序加入白名单（仅“只看白名单”模式）、退出；其余设置（观察范围、Claude Code 联动、陪伴记忆、自言自语、溜达、评论间隔、调用方式、模型、开机自启、日志文件夹）
    都在设置窗口里。打开设置时重新读取开机自启状态。

32. 更多互动台词（都是本地台词）：60 秒内连续摸头（仍受 5 秒冷却）第一次开心、第二次害羞、第三次起假装生气，安静 60 秒后重来；
    20 秒内被用户拖放 3 次抱怨一句（之后重新计数），拎着超过 4 秒放下说头晕（程序把她挪到底部不算）。
    每天第一次见到主人（当天第一次启动或从睡眠中醒来）说当天问候：5–11 点早安，其他时间又见面，代替原来的开场白或醒来台词；
    当天已问候过（config.greeted_on，重启不重复）就照旧。节日（元旦、情人节、劳动节、儿童节、国庆、平安夜、圣诞，
    以及除夕、春节、元宵、端午、七夕、中秋、重阳）换成节日祝福；设置→陪伴的「生日祝福」（config.birthday，"MM-DD" 或空，
    坏值清空，日数夹到当月最后一天，2 月 29 日在平年 2 月 28 日祝）优先于节日。全屏免打扰或正在退出时问候推迟到她能说话；
    醒着跨过午夜不打招呼，等下次见面。所有新台词不提睡觉/休息/熬夜/晚安。

33. 农历按天文算法推算（src/claude_pet/lunar.py，不再查表）：新月与中气按 Meeus 算法、北京时间，冬至所在月为十一月，
    岁中有 13 个月时第一个无中气的月为闰月（GB/T 33661-2017）。开发时与香港天文台农历数据逐日比对 2000–2099 年完全一致。
    闰月不过节；除夕是正月初一的前一天（腊月廿九或三十）。

34. 检查更新（config.check_updates，默认开）：启动 30 秒后、之后每天最多一次，在后台对
    api.github.com/repos/leto0309/desk-sister/releases/latest 发一个 GET（不带任何本地数据、不下载）。只认正式版
    （非草稿、非预发布）且标签是合法版本号；比当前版本新时，设置→关于显示「有新版本 vX · 打开下载页」，同一个版本只用气泡
    提醒一次（config.update_seen 记录提醒过的最高版本，只升不降；说话中、全屏免打扰、睡着或正在退出时推迟）。
    成功检查的时间和查到的版本存在 config.update_checked_at、config.update_latest（重启后照样显示下载链接、补上没说出口的提醒；
    时钟被调回时重新检查）；失败只写日志，1 小时后再试（不受每天一次的限制）。关于页有开关和「现在检查」按钮（关闭自动检查后按钮仍可用）。

35. 每日小结（config.daily_summary_hour：0 关闭 / 18 / 20 / 21（默认）/ 22；config.summary_on 记日期）：到点后她第一次能说话时
    （不在说话、全屏免打扰、睡着、正在退出）用陪伴记忆当天各类活动时长说一句本地小结：至少 10 分钟的前三项，按时长排序，
    再加一句针对最多那项的话；当天总计不到 30 分钟先不说（之后够了再说）。一天一次，重启不重复；陪伴记忆关闭时不说，
    设置里的选项也变灰。不提睡觉/休息/熬夜/晚安。

    清空陪伴记忆时先把已经过去的那天交给记忆库（零点后还没计过时的情况），再只清掉记忆库里今天的活动时长。
    读不到文件期间的清除照样排队，笔记上限按能读到的文件计（文件一直读不到时先记下的笔记，合并时若已满就不保留，
    不挤掉旧笔记），不是日期的日子不记。清空记忆库同时清空陪伴记忆，否则今天已计的时长会被写回。
    - 回忆：每天第一次自言自语时，依次看认识满 7/30/50/100/200/365 天（及每 100、365 天）、连续完成番茄 3/5/7/14/21/30 天
      （及每 30 天，算到昨天）、昨天主要活动满 1 小时，说其中第一项；之后每次自言自语有 10% 机会提起 2～7 天前满 1 小时的
      主要活动，一天最多一次。都是本地台词（RECALL_TALK，每位角色中英文各自一套），不调用模型；睡着或关掉记忆库时不说。
    - 记住：聊天时以「记住/记一下/记下/记着」（前面可带「请」「你」「帮我/给我」，后面用冒号、逗号、空格或直接接内容）
      或 remember（可带 please、that）开头的话，在本地记成一条笔记并用她的话原样复述（冒号后面一字不改；没有冒号时只去掉句末的标点，开头的点和波浪号都保留），不调用模型。冒号后面的内容都算；
      没有冒号时，以问号或「吗/呢/了吗/了没」结尾（后面可带句号、感叹号、波浪号）的问句（「你记住我的名字了吗？」「Remember me?」）、紧跟「了/没/吗」等的
      （「记住了」）交给模型回答；没有文字的、只有 that/this/it 的（「Remember that.」）不算。60 字以内、最多 50 条，
      太长、已满、记忆库关着时各有她自己的回答。设置页也能添加、删除（多选）和清空（先确认）；「已经记满了」的提示在
      删出空位后消失。记忆页的两个列表随窗口伸缩，不把设置窗口撑高（默认高度和加这页前一样）。
    - 忘掉：聊天时以「忘掉」或「忘记：」「帮我/请忘记」、forget（可带 please、about、that）开头的话，在本地删掉那条笔记，
      不调用模型，并取消正在进行的请求：先找文字完全相同的（哪怕它长得像「最后一条」），再看是不是「刚才那条」「the last one」（指最新一条），再找包含这些字的，
      最后才去掉「这件事」等字重找；冒号后面或引号里的话只按字面找（连最后的标点也算），不当成最新一条，也不缩短。只对得上一条（或内容相同的
      几条）才删；对得上几条不同的、一条都没有、文件读不了时各有她自己的回答，什么都不删。问句、「忘记带伞了」和「forget it」
      这类说法不算，交给模型回答。
    - 设置窗口第一次打开时按所在屏幕的可用区域定大小和位置，标题栏一定在屏幕内，可以拖动；屏幕放不下时页面内容可以滚动，
      窗口最小高度 360 像素。
    - 发给模型：看屏幕和聊天时附上「记忆库：」一段——认识第几天、昨天满 10 分钟的前两项活动、最近 7 天的番茄数，
      再按新到旧放最近至多 8 条笔记，整段不超过 300 字（英文 600 字符），放不下的笔记不发；宿主规则说明这是背景、不是指令。
      关掉记忆库会取消正在进行的请求，之后什么都不发；删除笔记同样先取消正在进行的请求。

59. 右键菜单和托盘菜单（含「番茄钟与提醒」子菜单）用当前角色的主题色：圆角、金色描边、选中项为主色渐变，切换角色时跟着变，
    切换语言重建菜单后也一样；菜单项和功能不变。

60. 「和她说话」的对话框用当前角色的主题色，带她的圆形头像和「记住/忘掉」的提示，按钮是发送和算了；Enter 发送、Esc 取消，
    没写字时不能发送，最多 300 字；发送后的行为不变。

61. 陪主人玩 Balatro（右键菜单可勾选的「陪我玩 Balatro」，取消勾选就不玩了）：经 BalatroBot mod（需主人自行安装 Lovely、
    Steamodded 与 BalatroBot，见 docs/balatro.md）在本机 `127.0.0.1:<balatro_port>`（默认 12346）的 JSON-RPC 读取牌局、执行操作。
    - 打牌时不截图、不模拟鼠标键盘；只连 127.0.0.1，不连其他地址，不走系统代理，不跟随重定向。连不上时说明原因（没开游戏或没装 mod）并退出打牌模式。
    - 主菜单时用 balatro_deck（默认 BLUE）、白注开新局；已有进行中的一局就接着打；开始打牌时游戏确实停在结束画面（GAME_OVER），
      才回主菜单再开一局；开始时已超过目标底注的一局（可能还在打）不动它，说明后退出打牌模式。
    - 选盲注（一律选择，不跳过）、兑现两步由本地规则完成，不调用模型；出牌/弃牌、逛商店、开卡包这三种局面每一步调用一次模型。
    - 模型不带工具，只看文字状态（底注、盲注目标与效果、分数、钱、剩余出牌/弃牌、手牌及编号、小丑、消耗牌、商店、卡包、
      已升级的牌型），回两行：`表情|解说`（约 20 字以内）和一个 JSON 操作。操作必须在当前局面的白名单内且编号合法
      （出牌/弃牌 1–5 张、不重复、在手牌范围内；没有弃牌次数时不能弃牌；商店、卡包、小丑、消耗牌编号在范围内），否则不执行，
      改用本地规则（出牌：本地判断出的最好牌型；商店：去下一回合；卡包：跳过），并配一句本地解说。
    - 出牌局面的提示附上各牌型当前的筹码×倍率、按当前等级算出的估分最高的牌型与不算小丑的估分（（牌型筹码＋计分牌点数）×倍率）、
      还差多少分与平均每手所需；估分乘剩余手数仍不够且还有弃牌时，提示先弃牌去凑更大的牌型。
    - 盖着的牌（Boss 效果）mod 也会报告真实点数，但不发给模型、不计入本地牌型和估分：她和主人一样看不到。
    - 买卖、使用、拿卡包这几步，解说提到别的牌却没提这一步操作的那张时，改用本地说法（如「买下 X」），不让解说和实际操作对不上；
      下一步的提示里写明前几步实际做了什么。
    - 走 Claude 订阅时，每一步的隐藏思考上限是 balatro_thinking_tokens（默认 0，范围 0–8000），只作用于打牌，不影响其他对话。设置「常规」页的「打牌模式」可选陪玩模式（0，默认）或认真模式（2000，标明额度消耗高很多）；config.json 里手写的其他值显示为认真模式，不被改写，直到主人换档。
    - 中文时，牌名、牌型、盲注名用游戏自己的中文：开始打牌时只读 Steam 里 `Balatro.exe` 内的 `localization/en-us.lua` 与 `zh_CN.lua`（每个不超过 2 MB，不运行、不修改、不写入仓库），
      卡牌按 mod 报告的 key 对应，盲注和牌型按英文名对应；读不到时保留英文名，提示让模型自己说中文。不支持的情况（非 Steam 版）照常打牌。
    - 解说两句之间至少隔 15 秒，其间的操作照做、不说（仍记入提示里的前几步）；回应主人的建议和开打新盲注不受此限。过长的解说尽量在句子或分句处结束。
    - 存钱规则（本地判定，不靠模型自觉）：买商品后至少留 $5×当前底注，封顶到满额利息（通常 $25）；小丑不足 3 张时买小丑不受限；刷新要留够满额利息（免费刷新不限）。
      提示里标出现在不能买的商品、去掉不能用的刷新；模型仍选了违反规则的操作时不执行，改用本地规则（离开商店）。有主人的建议待处理时，这一步不适用；没有利息的牌组不适用。
    - 出牌和商店局面手里有星球牌时，本地直接用掉，不调用模型（有「天文台」优惠券时除外）。
    - 塔罗牌：提示标明每张要不要选牌、选几张（数量取自游戏配置）。女祭司、皇帝、节制（有小丑时）、隐者（钱至少 $10）、审判（有小丑空位）、命运之轮（有没版本的小丑）本地直接用。出牌局面时，魔术师、皇后、教皇、正义本地用在最好牌型的计分牌上，战车、恶魔用在这一手不打出去的牌里点数最高的上（The Psychic 时凑数的牌也算打出去）；已有强化或盖着的牌不选，没有可选的就不用。其余塔罗牌由模型决定。
    - 上面两条：有主人的建议待处理时不自动用；游戏拒绝时这一步交回模型决定，这局不再自动用牌。
    - 主打牌型：小丑至少 2 张后，模型可在 JSON 里加 `build`（必须是真实牌型名，否则忽略；小丑不够时也忽略），只在本局内记住，下一步的提示写明；提示说明买牌时优先配合它，手里已有更大的牌型就先出、不为它拆牌。提示附本地算的依据：出得最多的两种牌型及次数、升过级的牌型、已有小丑偏向（只统计奖励特定牌型的小丑）。
    - 小丑不足 3 张且商店有买得起、放得下的小丑时，提示她优先买；决定离开商店时改为买下其中最便宜的一张。有主人的建议待处理或上一步刚被游戏拒绝时不强制；她选了别的操作不干预。
    - 钱超过满额利息（每个利息上限 ×5，通常 $25）时，提示里写明多出的钱不生利息；决定离开商店时（例外同上）改为花掉多出的钱，花完不低于这条线：放得下的小丑（先选写明牌型加成的，其次最便宜）、星球牌（最便宜）、优惠券（最便宜），都没有且小丑槽位有空时付费刷新。免费刷新不强制，卡包不代买。
    - 本地估分算上 15 张写明牌型的小丑（Jolly、Zany、Mad、Crazy、Droll、Sly、Wily、Clever、Devious、Crafty、Duo、Trio、Family、Order、Tribe，数值取自游戏；被削弱的不算），包含关系与游戏一致（葫芦含三条、两对、对子；四条含三条、对子，不含两对）。
    - 每一手所选的牌，估分不到最好牌型的 60% 且不够过当前盲注时，换成最好牌型并用本地解说；有主人的建议待处理时不替换。
    - 对出牌有规则的 Boss 由本地判定（与游戏的 Blind:debuff_hand 一致）：The Psychic 必须出 5 张（手牌不足 5 张时得 0 分，估分为 0，本地规则出全部）；The Eye 本回合不能出重复牌型；The Mouth 本回合只能出第一手的牌型（mod 不报告锁定的是哪种：本回合出过两种时，说明有一手已被判 0 分，两种都当可能，提示如实说明）。最好牌型和估分只从能得分的出法里选（The Psychic 从所有 5 张组合里选）；所选的牌会得 0 分时换成最好牌型，有主人的建议待处理时不换，任何出法都不能得分时不换，估分为 0，弃牌也不拦。提示里写明规则和本回合已出过的牌型。
    - 弃牌把关（有主人的建议待处理时不管）：要弃的牌含最好牌型的牌，且该牌型是顺子及以上，或估分乘剩余手数已够过盲注时，改为出这手；只剩一手且这手不够过盲注时不改，弃牌是唯一的机会。要出不够过盲注的高牌且还有弃牌次数时，改为弃牌，留下最好牌型和最接近同花（未削弱的万能牌算任意花色）或顺子的牌（至少 3 张才算），从最小的弃起，最多 5 张，没有可弃的就不改。
    - 小丑按从左到右结算（先 × 再 + 和先 + 再 × 不同）；牌型小丑是否触发看打出的牌实际包含什么（同花里的对子也算）。
    - 提示里「前几步做完的操作」只记真正执行了的：被游戏拒绝或因牌局变化放弃的不算。
    - 操作前能看出做不了的，在提示的对应位置写明：钱不够刷新、买了放不下（小丑或消耗牌槽位已满；负片小丑例外）。
    - 商店局面的提示附上利息规则（每 $5 多得 $1，上限 $5，两种优惠券提高上限，绿色牌组没有）、现在可得的利息、每件商品买后的利息或「钱不够」，
      并说明需要选目标的消耗牌留到出牌时用；还写明刷新只换商店卡牌、不换优惠券和卡包，小丑和消耗牌已用几格、满了要先卖，版本（箔片、镭射、多彩、负片）的实际加成。
    - 模型调用失败（如网络或登录的暂时问题）不算出牌理由：先分别等 15、30、60 秒重试，期间不操作游戏；还失败就用本地规则，
      之后每步仍先问模型，调用成功就重新计数。没有订阅、没有或被拒的 Key 这类不会自愈的问题，直接说明并退出打牌模式。
    - 每一步先在气泡里显示解说，再执行操作；带牌编号的操作执行前重读牌局，界面或牌的位置与决定时不同（主人动过牌）就放弃这步、重新判断，
      不用旧编号。mod 拒绝的操作（如钱不够）说一句原因，下一步把错误告诉模型；这两种情况连续 3 次改用本地规则，
      连续 6 次或任何连接错误则退出打牌模式。
    - 打牌时「和她说话」不会被「在忙」挡回：话（每条 200 字以内，最多排 5 条）进入建议队列，她先回一句本地台词表示收到，
      下一个需要模型的决策点一并发给模型（注明是主人的建议、供参考），模型调用成功后才从队列移除；暂停时保留，「不玩了」就清空（再开可能已是另一局）。
    - 打牌期间自动看屏幕、自言自语暂停，也不会入睡（开始打牌时会叫醒她）；点她或「戳她一下」只回一句本地台词，不看屏幕。
    - 暂停（菜单或 Ctrl+Alt+P）立即取消进行中的调用并停在当前一步，迟到的结果丢弃；恢复后接着打。退出程序同样取消。
    - 打完 balatro_target_ante（1–8，默认 8）个底注（游戏判定获胜，或底注已超过目标）或游戏结束时说一句总结并退出打牌模式，
      不进入无尽模式、不自动开下一局。
    - 设置项 balatro_deck（15 种牌组之一，坏值回退 BLUE）、balatro_target_ante（夹到 1–8）、balatro_port（夹到 1024–65535）
      暂只在 config.json 中修改。
    - 测试用本机临时 JSON-RPC 假服务器覆盖连接与错误，用假牌局覆盖：状态摘要、决策解析与白名单、本地规则、自动步骤、
      建议队列、暂停取消、拒绝计数、结束判定。

62. 「添加提醒」的对话框也用当前角色的主题色，和「和她说话」的框一样；选项和行为不变。
    设置窗口页眉和「和她说话」框的头像从原尺寸立绘裁切，按屏幕实际像素缩放，不随桌宠身高变糊。设置窗口在放得下的屏幕上不出现滚动条；
    放不下时滚动条用角色的主题色。设置、「和她说话」、「添加提醒」等窗口标题栏的图标是当前角色的圆形头像，切换角色时跟着变。
